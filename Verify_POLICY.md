Privacy Policy

Data Collected:

Discord Guild ID, Role ID, Channel ID (stored in config.json for bot configuration)
Discord User ID (stored temporarily in memory for up to 10 minutes during verification)

Data Usage: Used solely to operate the verification system.

Data Retention: Session data deleted within 10 minutes. Configuration data stored until manually removed.

Data Deletion: Contact us at https://discord.gg/dwAwR5X8en to request data deletion.
